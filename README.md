# Playground

A collection of small Java exercises from a Java Full Stack training program, organized into weekly folders (`introToJava`, `second.week.training`, `fourth.week.training`) plus standalone files at the root. Topics range from language basics (loops, conditionals, arithmetic, string/number manipulation) to introductory object-oriented programming (classes, constructors, constructor overloading).

Each file is a self-contained exercise rather than parts of one larger application.
